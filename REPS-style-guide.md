# REPS — visual style guide

## Brand
Use the supplied REPS logo without redrawing, recoloring, stretching, or cropping it. Display it on a light neutral background so its black lettering stays visible. Keep clear space around the mark; never place copy over it. The complete original PNG is embedded in the HTML.

## Palette
Colors sampled from the solid pixels in the supplied logo:

| Color | Hex | Role |
| --- | --- | --- |
| REPS orange | `#F87000` | Primary actions, practice momentum, key scores |
| REPS blue | `#0088B8` | Supporting panels, discovery metrics, focus outlines |
| REPS yellow | `#E8EF74` | Buyer dialogue, selected responses, featured pricing |
| Logo black | `#000000` | Original logo lettering |
| Interface near-black | `#101010` | Text, dark practice surfaces, borders |
| Off-white | `#FAFAF7` | Main canvas |

Use near-black text on orange and yellow. Use white text on blue. Do not use orange or yellow for small text on the light canvas.

## Typography
Headlines: Arial Black with Trebuchet MS and sans-serif fallbacks; heavy weight, tight tracking, compact lines. Body: Trebuchet MS with Verdana and sans-serif fallbacks. Utility labels: Courier New, uppercase, with open tracking. All fonts are local; no font download is required.

## Composition and motion
The logo’s circular arrow informs the circular rehearsal stage, concentric rings, and practice-loop theme. Keep the asymmetric editorial composition and 13px spacing rhythm. Use orange for the next action, blue for supporting feedback, and yellow for a moment of attention. Use square-edged dialogue strips and controls against the rounded stage. The restrained waveform repeats every 1.817 seconds and stops when reduced motion is requested.

## Interaction
Use clear text labels, visible keyboard focus, and color plus text to communicate selected states. Email stays in the page. Demo results reflect scripted response choices; no live AI service, account, or purchase is created.

## Application
Applied to the landing page, embedded logo, browser icon palette, navigation, practice scenario, diagnostics, pricing, buttons, selected responses, charts, and mobile layouts. The original private design seed is not included in the HTML.
